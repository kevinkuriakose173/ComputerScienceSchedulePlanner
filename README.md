# Computer Science Schedule Planner

A full-stack application designed to help Rutgers University students plan their Computer Science courses. This project uses graph-based data structures to model course prerequisites and provides insights into eligible courses, completed prerequisites, and paths to desired courses.

---

## Features

### 📚 Course Management
- Build a graph of all courses in the Rutgers Computer Science program using **Adjacency Lists**.
- Utilize **HashMaps** and **Linked Lists** to efficiently store and retrieve course relationships.

### 🧑‍🎓 User Input
- Users can input the courses they have completed to:
  - Generate a list of all prerequisites and courses already taken.
  - View all courses they are now eligible to take.

### 🔍 Pathfinding
- Input a target course to:
  - Identify all courses required to take before the target course.

### 🌐 Full-Stack Implementation
- Backend built with **Java** and **Spring Boot**.
- Frontend designed with **HTML/CSS** for an intuitive and user-friendly interface.

---

## Technologies Used

- **Backend:** Java, Spring Boot
- **Frontend:** HTML, CSS
- **Data Structures:** Adjacency Lists, HashMaps, Linked Lists
